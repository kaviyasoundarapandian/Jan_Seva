# Jan Seva: Technical Design Document

## 1. Purpose

Give citizens one simple, offline-capable, multilingual app for emergency help, reporting problems and finding government services, with privacy by default (data stays on the device).

## 2. Design goals

| Goal | How it is met |
|------|---------------|
| Works on low-end phones and weak networks | Single static file, no framework, service worker caching |
| Privacy | No backend; data in `localStorage` |
| Accessibility | Large touch targets, read-aloud, voice input, dark mode, ARIA labels |
| Reach | Many Indian languages, tap-to-call helplines |
| Easy to host | Static files only |

## 4. Application structure

The app is one `index.html` made of a base app plus numbered add-on modules, each in an IIFE (immediately invoked function) that extends the base.

```mermaid
flowchart LR
  Base["Base app: T (translations), V (views), render(), tab router"]
  A2["Add-on 2: services, payments, documents, media"]
  A3["Add-on 3: password + TOTP 2-step"]
  A5["Add-on 5-7: front-page boxes, splash, radio, home order"]
  A8["Add-on 8-9: pension tracker, self care, help hub, money, learning"]
  A10["Add-on 10-12: careers, farm storage, category pages, sign-language access"]
  A14["Add-on 14: Panchangam + Nanba chat"]
  Base --> A2 --> A3 --> A5 --> A8 --> A10 --> A14
```

### Core pieces

| Piece | Role |
|-------|------|
| `T.<lang>` | Translation dictionaries (`en`, `hi`, and others loaded via translation) |
| `V.<name>` | View functions; each returns an HTML string for one screen |
| `render()` | Paints the current tab into the page and updates the bottom navigation |
| `data-go="<tab>"` | Click handlers switch tab (event delegation on `document`) |
| `sv(key, value)` / `ld(key, default)` | Save / load JSON in `localStorage` with the `ns_` prefix |
| `esc()` / `E()` | HTML escaping for user text |

## 5. Data model (localStorage)

All keys are prefixed `ns_`. Values are JSON.

| Key | Shape | Description |
|-----|-------|-------------|
| `ns_prof` | `{n, a, g, q, s, dt, ph, em, bg, h, sl}` | Profile: name, age, gender, qualification, state, district, phone, emergency contact, blood group, plus health and sleep data |
| `ns_contacts` | `[{n, p}]` | Emergency contacts (name, phone) |
| `ns_reports` | `[{id, cat, desc, photo, loc, anon, at, done, rating}]` | Problem reports. `id` format `NS-XXXXXX`, generated by `crypto.getRandomValues` |
| `ns_rem` | `[{n, d}]` | Reminders (name, date) |
| `ns_pen` | `{...}` | Pension tracking |
| `ns_places` | `[...]` | Saved places |
| `ns_sec` | `{...}` | Security settings (PIN / 2-step) |
| `ns_nanba` | `[{r, h}]` | Last 40 chat messages (`r` = `me` or `bot`) |
| `ns_nb_api` | `string` | Optional AI endpoint URL |
| `ns_lang`, `ns_ul` | `string` | Language selection |

Report status labels: Saved, Sent to authority, Reached authority, In progress, Resolved.

### 6.3 Language and read-aloud

English and Hindi are built in. For other languages, text is translated through Google Translate when online. Read-aloud uses the browser voice for the chosen language and falls back to `en-IN`.

## 7. Security design

| Risk | Mitigation |
|------|------------|
| XSS from user text | Escape before inserting into HTML |
| Secrets in front-end | None stored; AI endpoint must be your own server, HTTPS only |
| Unauthorized access to a phone's data | Optional PIN, password and TOTP 2-step |
| Privacy | No analytics, no backend; data stays on device |
| Mixed content | HTTPS required for the AI endpoint; service worker needs HTTPS |

Recommended hardening for deployment: Content-Security-Policy, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`.

## 8. Offline strategy

The service worker caches the app shell. Online-only features (translation, weather, external links) show a message when offline. Saved data is always available.

## 9. Third-party services

| Service | Used for | Data sent |
|---------|----------|-----------|
| Google Translate (`translate.googleapis.com`) | Translating screen text | Text to translate |
| Open-Meteo | Weather | Latitude and longitude |
| Google Fonts | Fonts (Mukta, Playfair Display) | Standard font request |
| Official `.gov.in` portals, YouTube, OpenStreetMap | Links | None from the app |

## 10. Limitations and future work

- Reports are stored on the phone only; "Sent to authority" is a status label, not a real submission. Integration with an official grievance system would need a backend.
- Single large HTML file; splitting into modules and adding a build step would help maintenance.
- Add automated tests (Playwright) on top of the manual test cases.
- Replace external translation with bundled language packs for full offline use.
