# Jan Seva — Test Cases

**App:** Jan Seva (`index.html`, Android WebView)  **Type:** manual / smoke  **Priority:** P1 = release blocker, P2 = important, P3 = nice to have

**Setup:** fresh install (or clear site data). For data-heavy tests run `load-sample-data.js` first (see README).

## 1. Launch, language, onboarding

| ID | Priority | Steps | Expected result |
|---|---|---|---|
| TC-001 | P1 | Open the app | Splash with logo, "Jan Seva" and tagline appears, then the welcome screen |
| TC-002 | P1 | Tap **Continue as guest** | Home opens with search bar, guest banner, Emergency button and tiles |
| TC-003 | P1 | Open language dropdown, choose Hindi, then Tamil, then English | UI text changes immediately each time; selection persists after reload |
| TC-004 | P2 | Select each of the 22 languages | No blank labels; missing strings fall back to English; Urdu/Sindhi/Kashmiri show right-to-left |
| TC-005 | P2 | Tap **Create profile**, leave name empty, save | Validation message "Please enter your name" |
| TC-006 | P1 | Create profile with name, age, state, qualification, 4-digit PIN | Profile saved; next launch asks for PIN |
| TC-007 | P1 | Enter wrong PIN, then correct PIN | "Wrong PIN" toast, then access granted |
| TC-008 | P2 | Create PIN with mismatching confirmation or 3 digits | Error "PINs must match and be 4-6 digits" |
| TC-009 | P2 | Tap "Not you?" and confirm | Local profile deleted; welcome screen shown |

- [ ] `index.html` console has no uncaught errors
